## Project Description
Evaluating if a robot facilitator that tracks each person's speaking time and turns toward the least active participant can make participation in a small group discussion more even than a robot that chooses addressees at random. 

## Specifications
- 21 participants, groups of 3 (7 groups)
- Computational focus: improving some aspect of robot performance efficiency, or decision-making. Investigate a computational approach that enhances the robot's behaviour and evaluate its effectivness. Compare your proposed approach against an appropriate baseline method.

- Grading
    • Choice of Question and Hypothesis (15 points)
    • Study Design (20 points)
    • Implementation (30 points)
    • Measures, Metrics, and Data Analysis (20 points)
    • Report (15 points)
